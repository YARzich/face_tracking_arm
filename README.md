# face_tracking_arm

Роборука UFACTORY xArm6 с камерой над экраном: находит лицо, оценивает его
положение в 3D и плавно направляет к нему экран. При нескольких видимых лицах
выбирает ближайшее; после потери лица возвращается в исходную позу или ищет
новую цель. Pet-проект на ROS 2 Jazzy, с тестовыми сценами в Gazebo Harmonic
и отдельными запусками для реальной руки.

## Запуск на xArm6

**[Пошаговое руководство: Docker → конфигурация → запуск](docs/hardware.md).**

Все команды выполняются в папке проекта. Порядок первого запуска:

1. Подготовьте Docker-образ: `./run prepare`.
2. Заполните [config/hardware.yaml](config/hardware.yaml): IP руки, камеру,
   размеры крепления и стола.
3. Подключите калибровку камеры или выполните её по руководству.
4. Проверьте изображение:

```bash
./run cpu --camera-only --show-image
```

После проверки камеры и готовности руки в UFACTORY Studio остановите просмотр
через Ctrl+C и запустите слежение. **Рука может сразу начать двигаться.**

```bash
./run cpu
```

Для стереокамеры используйте `./run stereo`. Модель YuNet и зависимости входят
в Docker-образ. Сглаживание Калмана включено в шаблоне `hardware.yaml`;
настройки для обычной камеры и стерео раздельные.

Для выбора фильтра на один запуск добавьте `--point-filter kalman`,
`--point-filter one_euro` или `--point-filter off`.
[Команды и остальные аргументы Docker](docs/hardware.md#выбрать-сглаживание-при-запуске).

После изменения настроек достаточно остановить и снова запустить команду.
Обновление самой программы требует нового образа; изменения IP, камеры,
калибровки, геометрии и слежения — нет.
Подробности калибровки и координат — в [описании камер](docs/cameras.md).

## Как устроено

Детектор YuNet находит рамку лица. Обычная камера оценивает расстояние по
ширине рамки; стереопара — по разнице между двумя изображениями. Измеренная
точка сохраняет время кадра и преобразуется через TF с учётом движения камеры.

Локальный контроллер рассчитывает скорости суставов с ограничениями движения
и столкновений. MoveIt строит пути возврата и смены позы в отдельном потоке.
Один JointTrajectoryController исполняет общую очередь команд. Поиск и
слежение используют тот же контур движения.

[Архитектура, ROS-интерфейсы и настройки управления](docs/architecture.md).

## Ограничения

- Расстояние от одной камеры приблизительное: размер и поворот лица влияют на оценку.
- Стерео требует калибровки и синхронных кадров.
- Полные обходы вокруг руки могут требовать обратного разворота: суставы xArm6
  имеют заводские ограничения угла.
- Геометрия стола и крепления задаётся вручную. Обнаружение лица не заменяет
  обнаружение препятствий или защиту человека от столкновения.
- GPU-вариант глубины экспериментальный: в тестовой сцене он давал большую
  ошибку расстояния и не используется в основных запусках.
