# Запуск Lite 6 через Docker

Нужен Linux с Docker Engine. ROS и Python-пакеты на компьютере устанавливать не нужно.
Все команды ниже выполняйте из папки `face_tracking_arm`.

## 1. Подготовить Docker и образ

Если Docker уже установлен, переходите к `./run prepare`.
Если его нет, на Ubuntu выполните:

```bash
sudo apt update
sudo apt install --no-remove docker.io
sudo systemctl start docker
```

Подготовьте окружение проекта:

```bash
./run prepare
```

При необходимости введите пароль sudo. Если в `dist` есть готовый образ
для этого компьютера, он загрузится оттуда. Иначе образ соберётся автоматически;
понадобятся интернет и время на первую сборку. Повторять подготовку при каждом
запуске не нужно.

## 2. Заполнить config/hardware.yaml

```bash
nano config/hardware.yaml
```

Заполните:

| Поле | Что указать |
|---|---|
| `robot.ip` | IP руки из UFACTORY Studio |
| `robot.base_xyz_m` | Положение основания; Z — высота от пола, в метрах |
| `table` | Размеры и положение столешницы для проверки столкновений |
| `monitor`, `camera_mount` | Размеры, масса и положение установленного экрана и камеры |
| `tracking.idle_behavior` | Для первого запуска оставить `rest` |
| `motion.speed_scale` | Для первого запуска оставить `0.25` |

Все размеры `_m` — **метры**: `0.10` = 10 см. Масса `_kg` — килограммы.
Остальные параметры и единицы подписаны прямо в конфиге.
Поля `perception.python_executable` и `model_dir` для стандартного запуска менять не нужно.

Подключите руку по Ethernet. У компьютера и руки должны быть разные IP
одной подсети. В UFACTORY Studio задайте общую массу экрана, камеры и крепления
и их центр тяжести. Общая нагрузка Lite 6 — до 1 кг.

### Обычная USB-камера

Посмотрите доступные устройства:

```bash
./run devices
```

В `mono_cpu` оставьте `source: usb`, `rectification: raw`.
В `mono_cpu.left.device` укажите путь своей камеры. Начните с 640×480, 30 FPS.

Если калибровка уже есть, укажите путь к её YAML в `mono_cpu.left.calibration_file`.
Если её нет, оставьте поле пустым и выполните:

```bash
./run calibrate cpu --size 8x6 --square 0.025
```

Нужна плоская шахматная доска. `8x6` — **внутренние углы**, `0.025` — размер
клетки **в метрах**; подставьте размеры своей доски. Покажите доску под разными
углами и у краёв кадра. Нажмите **CALIBRATE → SAVE**, затем Ctrl+C в терминале.
Файл сохранится в `config/calibration/mono_cpu/left.yaml` и будет использован
автоматически. Калибровку выполняйте один раз для выбранного разрешения и фокуса.

### Стереокамера

1. Запустите ROS-драйвер своей камеры с `ROS_DOMAIN_ID=71`: уже установленный
   или в отдельном контейнере производителя с сетью `host`. Он должен выдавать
   левое и правое изображения и `CameraInfo` для каждого.
2. В `stereo` оставьте `source: ros`. Укажите `image_topic`, `info_topic` и
   `frame_id` для `left` и `right` из драйвера камеры.
3. Выберите `rectification: rectified`, если драйвер уже выравнивает изображения.
   Оставьте `baseline_m: 0.0`, если расстояние между объективами есть в калибровке;
   иначе укажите его в метрах. Начните с `sync_slop_sec: 0.005`.
4. Укажите положение объективов в `optical_xyz_m`. Если TF задаёт проект,
   отключите TF в драйвере камеры. [Настройка TF и пояснения параметров](cameras.md).

Для двух обычных USB-камер поставьте `source: usb`, `rectification: raw`,
укажите два разных `device`, оставьте `calibration_file` пустыми и выполните:

```bash
./run calibrate stereo --size 8x6 --square 0.025
```

После **CALIBRATE → SAVE** и Ctrl+C файлы появятся в
`config/calibration/stereo/` и будут использованы автоматически.
Для движущихся лиц требуется синхронная съёмка обеими камерами.

## 3. Проверить камеру и запустить руку

Сначала только камера, без подключения к руке:

```bash
./run cpu --camera-only --show-image
```

Для стерео замените `cpu` на `stereo`. Покажите лицо: должна появиться зелёная
рамка, а в терминале — `OK` и координаты. Остановите проверку через Ctrl+C.

Закрепите основание, освободите место для движения и держите аварийную кнопку
доступной. **Следующая команда включает управление и может сразу двигать руку.**

```bash
./run cpu
```

Для стерео:

```bash
./run stereo
```

Остановка — **Ctrl+C**. При неожиданном движении нажмите аварийную кнопку руки.
Желаемый отступ от лица не заменяет защиту от столкновения с человеком.

После изменения конфига достаточно перезапуска. Для окна камеры добавьте
`--show-image`. Для другого конфига: `./run cpu --config /путь/hardware.yaml`.

## Перенос на другой компьютер

На компьютере с подготовленным образом:

```bash
./run export
```

Скопируйте папку проекта вместе с `dist` на другой компьютер и выполните там
`./run prepare`. Готовый образ подходит компьютерам той же архитектуры
(Intel/AMD или ARM64). После изменения кода пересоберите образ: `./run build`.
