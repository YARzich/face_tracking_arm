# Симуляция кинематики

Сначала выполните [сборку пакета](../CONTRIBUTING.md). Затем в новом терминале:

```bash
source /opt/ros/jazzy/setup.bash
source ~/ros2_ws/install/setup.bash
ros2 launch face_tracking_arm tracking_sim.launch.py
```

Если workspace расположен иначе, замените `~/ros2_ws` своим путём.
Для этого сценария не нужны нейросетевые модели: источником служит искусственная
точка лица. Камеры и реальные изображения проверяются [отдельно](tracking_vision.md).

Полезные launch-аргументы:

- `headless:=true` — симуляция без графического клиента;
- `test_face_scenario:=stationary|circle|people|walk_around|disabled` — источник точки;
- `visualize_target:=false` — отключение визуального маркера;
- `servo_backend:=standard` — MoveIt Servo для отдельного сравнения.

По умолчанию выбраны `people` и собственный `collision_aware` контроллер.
Каждый запуск должен иметь единственный источник `/face/center`.

## Тестовые цели

`people` повторяет **132-секундный цикл**:

- 0–24 с: три человека спереди, движения головы, исчезновение и смена цели;
- 24–72 с: восемь людей по очереди вокруг стола, по 6 с на каждого;
- 72–120 с: человек ростом 1.80 м делает полный медленный обход стола;
- 120–132 с: цель исчезает; после HOLD остаётся время завершить REST,
  затем цикл повторяется.

Неподвижные цели расположены через 45° на расстоянии 0.85 м от центра
стола. Обозначения сторон относятся к осям `world`, основание руки — в `(0, 0)`.

| Время от старта сценария | Сторона | Рост | Высота центра лица |
| --- | --- | ---: | ---: |
| 24–30 с | Спереди, +X | 1.60 м | 1.48 м |
| 30–36 с | Спереди слева, +X/+Y | 1.75 м | 1.63 м |
| 36–42 с | Слева, +Y | 1.90 м | 1.78 м |
| 42–48 с | Сзади слева, −X/+Y | 1.65 м | 1.53 м |
| 48–54 с | Сзади, −X | 1.80 м | 1.68 м |
| 54–60 с | Сзади справа, −X/−Y | 2.00 м | 1.88 м |
| 60–66 с | Справа, −Y | 1.70 м | 1.58 м |
| 66–72 с | Спереди справа, +X/−Y | 1.85 м | 1.73 м |

Высота считается **от пола**, центр лица находится на 12 см ниже макушки.
Высота стола 0.75 м к ней не прибавляется. `stationary` и `circle` также
используют лицо человека ростом 1.80 м: средняя высота точки 1.68 м.

Отдельный непрерывный обход запускается так:

```bash
ros2 launch face_tracking_arm tracking_sim.launch.py test_face_scenario:=walk_around
```

Точка идёт против часовой стрелки при взгляде сверху: +X → +Y → −X → −Y → +X.
Радиус — 0.85 м, один оборот — 48 с, высота лица — 1.68 м с покачиванием
±1 см. На стыке оборотов нет скачка положения или скорости цели.
Красная сфера показывает лицо; модели тела человека в сцену не добавляются.

Неподвижные люди сменяются мгновенно, как выбранное лицо при переключении
между людьми. Сценарий намеренно проверяет все стороны, включая положения,
в которых рука может ограничить движение по своей кинематике.

Во время прогона следите за `/tracking/diagnostics` и `/servo_node/diagnostics`.
Проверяйте не только направление экрана, но и плавность суставов, восстановление
после потери лица и возврат после полного обхода. Завершение — Ctrl+C.
